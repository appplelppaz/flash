# 例文の作り方

このリポジトリの語彙リスト（`vocab/*.tsv`）で使う、例文の決まりごと。
`netflix-subs-to-vocab` スキルで字幕から語彙リストを作るときは、この文書に従う。

## 考え方

語彙は、**コアの語を骨組みとして、そこに語を足していく**ことで増える。

- **語彙リスト**は骨組み。覚えるべき語をここに置き、カードで確実に定着させる。
- **例文**は上乗せの場。リストには入れない語を毎回 1〜2 語まぜて、
  骨組みの語を思い出すついでに、その語に出会わせる。

だから例文は「その単語を入れておく箱」ではない。
**リストに無い語を運ぶ乗り物**として書く。

TSV の 5 列目に、その例文で上乗せした語とその訳を書く。
アプリは 5 列目の語を例文の中で見つけて下線を引き、訳の段階で意味を添える。

```
単語 ⇥ 日本語訳 ⇥ 例文 ⇥ 例文の日本語訳 ⇥ おまけの語（語=訳; 語=訳）
```

```
keep an eye on	見張る・気にかけておく	Keep an eye on the crate while I bribe the guard.	見張りを買収する間、その木箱を見ていてくれ。	crate=木箱; bribe=買収する
```

見出し語は `keep an eye on`。学ぶのはそれだけではなく、`crate` と `bribe` も一緒に運ばれる。

## 四つの決まり

### 1. 例文ごとに、リストに無い語を 1〜2 語入れる

- **例文全体の 8 割以上**に入れる。1 文につき 1〜2 語。3 語を超えると主役が消える。
- **リストの見出し語は入れない**（それは上乗せではなく復習になってしまう）。点検で弾かれる。
- 選ぶ語は、その作品にしか出てこない語ではなく、**次にどこかで会う語**にする。
  中頻度の名詞・動詞・形容詞（`warehouse`・`bribe`・`stubborn`）や、
  よく使う句動詞（`hand over`・`slip out`）。固有名詞・専門語は避ける。
- **不規則変化に注意。**下線を引く仕組みは規則変化しか追えない。
  `bury → buried` `sound → sounded` は拾えるが、`go → went` `keep → kept` は拾えない。
  上乗せに選ぶなら、例文の中では原形か規則変化の形で使う。

### 2. 5 列目に、語と訳を正確に書く

- 例文の中で使った形ではなく、**辞書形**を書く（`sounded` ではなく `sound`）。
- 訳は短く 1〜2 語義。`;` で区切って並べる。
- **例文に出てこない語を書かない。**点検が「例文に見当たらない」として弾く。

### 3. 場面を借りる

作品の世界をそのまま使う。金庫、倉庫、深夜の電話、言い訳、裏切り——
**具体的な物と、何かがかかっている状況**を書く。
ただし**その場面を知らなくても意味が分かる文**にする。

字幕の行をそのまま使えるのは、それ単独で立つときだけ。
断片・相づち・掛け合いの片方・場面あってのせりふは、自分の文に書き換える。

```
✗ nonsense	たわごと	That's nonsense.	そんなのばかげている。          ← 中身も上乗せも無い
✓ nonsense	たわごと	Spare me the nonsense and hand over the key.	たわごとはいいから、鍵をよこせ。	spare=（手間を）省いてやる; hand over=引き渡す
```

### 4. 短く、声に出して自然に、楽しく

- 英・西・仏は **8〜16 語**、中国語は **12〜28 字**。1 文、長くても 2 節。
- アプリが読み上げる。書き言葉より**話し言葉**に寄せる。
- 見出し語は与えた語義で使う。面白さのために意味をずらさない。

淡々と正しいだけの文は手がかりにならない。次のどれかを混ぜる。

| 手 | 例 |
| --- | --- |
| **小さな落差** | `I can put up with the smell, not the silence.` |
| **人の気配** | `She turned down the job to chase a smaller dream.` |
| **軽い皮肉** | `Their offer came with a threat wrapped inside.` |
| **続きが気になる** | `He confessed at the last minute, with the engine running.` |
| **60〜80 語のまとまりで筋を通す** | 同じ登場人物・同じ倉庫・同じ夜。続けて出るカードが一本の話に見える |

避けるもの——`This is a pen.` のような教科書文、辞書の言い換えをそのまま文にしたもの、
主語が誰でもいい無色の文。

## 例文の日本語訳

- 例文の**忠実で自然な**訳。画面には出さず読み上げるだけなので、体裁より正確さ。
- Netflix の日本語字幕は尺に合わせて崩れていることが多い。**必ず読み直して、合っていなければ書き直す**。

## 点検

書き終えたら必ず通す。基準を満たさなければ終了コード 1 で落ちる。

```sh
node tools/check-examples.js vocab/en_papel_s1.tsv --list
awk -F'\t' 'NF!=5{print "BAD "NR}' vocab/en_papel_s1.tsv
```

| 見るところ | 目安 |
| --- | --- |
| `おまけの語あり` | **80% 以上** |
| `1 文あたり` | 1.0〜2.0 語 |
| `例文に見当たらない` | **0 件**（5 列目の書き間違い） |
| `リストにある語` | **0 件**（上乗せになっていない） |
| `長すぎる例文` | 0 に近づける |

`--list` を付けると、直すべき語がそのまま並ぶ。
