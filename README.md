# Flashcards

言語ごとの単語帳から任意の語数を選び、**選んだ単語がすべて学習済みになるまで繰り返し出題する**単語学習アプリです。
1 枚のカードは **単語 → 日本語訳 → その単語を含む例文** の順に展開し、
**単語 → 日本語訳 → 例文 → 例文の日本語訳 → 例文** の順に自動で読み上げます
（例文の日本語訳は読み上げのみで、画面には表示しません）。**自動めくり**にも対応しています。

ビルド不要・依存パッケージゼロのバニラ JavaScript で、`index.html` を開くだけで動きます。

## 使い方

```sh
open index.html     # そのまま開く
npm start           # ローカルサーバー → http://localhost:8080
```

1. **言語を選ぶ** — 英語 / 中国語 / スペイン語 / フランス語。
2. **範囲と語数を決める** — すべて / 苦手のみ / ★ のみ、出題語数（既定 20）。
3. **学習する** — 3 段階が進み、最後に「わかった / わからなかった」で判定します。
   選んだ単語が**すべて学習済みになるまで**終わりません。
4. **結果を見る** — 解答回数・正答率・所要時間・連続学習日数が残ります。

### 自動再生と自動めくり

- **自動再生** — 各段階が表示された時点で読み上げます。読み上げの順番は
  **単語（現地語）→ 日本語訳（日本語）→ 例文（現地語）→ 例文の日本語訳（日本語）→ 例文（現地語）** です。
  最後にもう一度例文を聞くことで、意味を理解したうえで音を確認できます。
- **自動めくり** — 読み上げが終わってから設定した間隔（既定 4 秒）を計測し、次の段階へ自動的に進みます。
  カード下部のバーが残り時間を示します。学習画面の「⏸ 自動めくり」ボタン（または `P` キー）で
  いつでも一時停止・再開できます。
- 最後の段階まで自動で進んで判定しなかった場合、その単語は**記録されずにもう一度出題**されます
  （正答率や解答回数には影響しません）。手を止めて聞き流す使い方でも進捗が汚れません。

### キーボード操作

| キー | 動作 |
| --- | --- |
| `Space` / `Enter` | 次の段階を表示 |
| `→` / `2` | わかった（最後の段階で） |
| `←` / `1` | わからなかった（最後の段階で） |
| `P` | 自動めくりの一時停止・再開 |

## 機能

| 機能 | 内容 |
| --- | --- |
| 言語別の単語帳 | 英語 60 語 / 中国語・スペイン語・フランス語 各 40 語（すべて例文つき） |
| 3 段階の提示 | 単語 → 日本語訳 → 例文（例文の日本語訳は読み上げのみ） |
| 出題語数の指定 | 設定のデフォルト（**20**）＋ 学習前に ± ボタン・プリセットで変更 |
| 学習済みまで反復 | 設定回数だけ連続正解するまで、その単語はキューから外れない |
| 自動再生 | 単語 → 日本語訳 → 例文 → 例文の訳 → 例文 の順に Web Speech API で読み上げ |
| 自動めくり | 読み上げ後に一定間隔で段階を自動送り。一時停止・再開に対応 |
| 出題範囲の切り替え | すべて / 苦手のみ / ★ お気に入りのみ |
| 単語一覧・検索 | 検索（単語・訳・例文）＋フィルター（未学習・学習済み・苦手・★） |
| 自作単語 | 例文つきで追加・編集・削除。収録単語と同じように出題される |
| 学習統計 | 学習済み語数・連続学習日数・通算正答率 |
| バックアップ | 設定・進捗・お気に入り・自作単語を JSON で書き出し／読み込み |
| テーマ | 端末に合わせる / ライト / ダーク |

## 設定

| 項目 | デフォルト | 説明 |
| --- | --- | --- |
| 出題する単語数 | **20** | 1 回の学習で出題する語数。対象より多い場合は自動で丸められます |
| 学習済みと判定する連続正解回数 | 2 | この回数連続で正解すると学習済み |
| 出題の向き | 単語 → 意味 | 「意味 → 単語」を選ぶと最初の 2 段階が入れ替わります |
| 単語の選び方 | 未学習・苦手を優先 | ランダム / 間違えた回数が多い順 |
| テーマ | 端末に合わせる | ライト / ダーク |
| 読み上げの自動再生 | オン | 単語・日本語訳・例文・例文の訳の自動読み上げ |
| 自動めくり | オン | 段階の自動送り |
| 自動めくりの間隔 | 4 秒 | 1〜20 秒（読み上げが終わってから計測） |

設定・進捗・お気に入り・自作単語はすべて `localStorage` に保存され、次回起動時に復元されます。

## 学習アルゴリズム

- 選ばれた単語はキューに入り、1 枚ずつ出題されます。
- **正解**すると連続正解数が 1 増え、設定回数に達した時点で学習済みになりキューから外れます。足りない場合は 6 枚ほど後ろへ。
- **不正解**なら連続正解数は 0 に戻り、3 枚ほど後ろに積み直されて必ず再出題されます。
- **判定しなかった**場合（自動めくりで通過）は記録せずに後ろへまわします。
- キューが空になる ＝ 選んだ単語がすべて学習済み、でセッション終了です。

## 単語を追加する

アプリ内の「単語一覧・編集 → ＋ 単語を追加」から、例文つきで追加できます。

収録単語そのものを増やす場合は `js/decks.js` の該当言語の `words` に追記します。

```js
{
  term: 'grateful',
  reading: 'ˈɡreɪtfl',
  meaning: '感謝している',
  example: "I'm grateful for your advice.",
  exampleJa: 'あなたの助言に感謝しています。'
}
```

`reading` は任意です。`example` を省くと例文の段階が飛ばされ、`exampleJa` を省くと例文の訳の読み上げが省かれます。
ID は `term` から自動生成されるため、途中に挿入しても既存の学習進捗はずれません。
新しい言語は `{ id, code, lang, name, words }` の deck を足すだけです（`lang` は読み上げ用のロケール）。

## 構成

```
index.html        画面のマークアップ（7 画面）
css/styles.css    デザイン（モノクロ基調・ライト / ダーク対応）
js/decks.js       単語帳データ（例文つき）＋自作単語の合流
js/storage.js     設定・進捗・お気に入り・自作単語・統計の保存
js/session.js     学習セッションと提示順・読み上げ順のロジック（DOM 非依存）
js/app.js         画面の描画とイベント処理
tests/            ロジックと単語データのテスト
```
