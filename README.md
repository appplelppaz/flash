# Flashcards 単語帳

Netflix / Language Reactor の字幕から作った語彙リストで学ぶ、**iPhone 向けのフラッシュカード**です。
`netflix-subs-to-vocab` スキルが書き出す TSV をそのまま取り込めます。

- **指だけで学習** — 上下スワイプで判定、左右で前後、タップでめくる、長押しで一時停止。
- **文字の少ない画面** — 画面の表記は英語で、アイコンで通じるものは文字を置いていません
  （`.claude/skills/minimal-ui` に決まりをまとめてあります）。判定はカードの色のまたたきで返します。
- **とにかく大きく** — カードの空きを実際に測って、入る限りいちばん大きな文字で出します。
  iPhone を横に持つと上下のバーが消え、操作アイコンは親指の届く右端に寄ります。
- **二つのモード** — **例文つき**（例文 → 単語 → 訳）と、例文を出さずに単語と訳だけを短い間隔で回す**単語だけ**。
- **出す順番** — リスト順 / **ランダム** / 苦手を先に。学習を始める画面でその場で選べます。
- **例文から覚える** — 例文つきモードの既定は **例文 → 単語 → 訳**。文の中で出会ってから語を確かめる並びです。
- **例文で語彙を上乗せ** — リストはコアの骨組み。例文には**リストに無い語**を毎回 1〜2 語入れてあり、
  下線を引いて訳を添えます。1 枚のカードで、覚える語のまわりの語も一緒に増えます。
- **読み上げ** — 例文（現地語）→ 例文の訳（日本語）→ 単語 → 訳の順に自動で読み上げます。声・速さ・範囲を選べます。
- **2 周する** — 1 枚のカードで、例文 → 単語 → 訳 の組を**もう一度はじめから**見せて読み上げるモードがあります。覚えて次へ進めます。
- **自動めくり・自動送り** — 読み上げが終わってから、次の表示へ・次の単語へ自動で進みます。
- **オフラインで動く PWA** — ホーム画面に追加すれば、電波が無くても学習できます。
- **収録リスト 10,128 語** — 英検1級以上 / HSK 6〜9級 / 生活スペイン語 3000 / 生活フランス語 3000。

ビルド不要・依存パッケージゼロのバニラ JavaScript です。

## 使い方

```sh
npm start      # http://localhost:8080 を開く
```

Service Worker（オフライン対応）は `https://` か `localhost` でだけ動きます。
GitHub Pages に置く場合は、リポジトリの Settings → Pages でこのブランチを公開すればそのまま動きます。

iPhone では Safari で開いて **共有 → ホーム画面に追加**。以後はアプリとして起動し、
機内モードでも学習できます。

## 字幕から単語リストを作って取り込む

1. Language Reactor で字幕を書き出す（`lln_excel_subs*.xlsx`）か、`.srt` を用意する。
2. Claude に「この字幕から語彙リストを作って」と頼む（`netflix-subs-to-vocab` スキルが動きます）。
   スキルは同梱の抽出器を使います。

   ```sh
   pip install jieba openpyxl --break-system-packages -q   # jieba は中国語のときだけ
   python3 tools/extract_vocab.py "字幕ファイル" -o candidates.tsv
   ```

3. 出来た `vocab/<lang>_<title>.tsv` を、アプリの **＋ →（ファイルを選ぶ／貼り付け）→ ✓**。

取り込める形は **タブ区切り・ヘッダーなし**。4 列に、任意の 5 列目を足せます。

```
単語	日本語訳	例文	例文の日本語訳	おまけの語（語=訳; 語=訳）
keep an eye on	見張る	Keep an eye on the crate while I bribe the guard.	見張りを買収する間、その木箱を見ていてくれ。	crate=木箱; bribe=買収する
```

**5 列目**は、その例文の中に入れた「リストに無い語」とその訳です。
アプリはこの語を例文の中で見つけて下線を引き、訳の段階で意味を添えます。
語彙リストで骨組みを固めながら、例文でそのまわりの語を増やすための列です。
書き方は [`vocab/EXAMPLES.md`](vocab/EXAMPLES.md) にまとめてあります。5 列目は省いても構いません。

ファイル名が `es_lacasadepapel.tsv` のようになっていれば、言語とリスト名を自動で読み取ります。
それ以外は中身から言語を推定します（英語・中国語・スペイン語・フランス語）。
抽出器が出す 8 列の候補ファイル、2〜3 列だけの行、重複行も読めます
（重複はまとめ、訳の無い行は飛ばして理由を知らせます）。

`vocab/en_sample.tsv` は動きを確かめるための見本です。

## 学習画面の操作

画面に出るのは**いま見るものだけ**です。例文つきモードでは **例文 → 単語 → 訳** の順に進み、
済んだものは小さく残り、いま見るものが大きくなります。

文字の大きさは決め打ちではなく、**カードの空きに合わせてその都度決めます**。
短い語なら画面いっぱいに、長い例文なら折り返しても収まる大きさに落ち着くので、
端末や持ち方が変わっても、はみ出さずにいちばん大きな文字になります。
画面を回すと測り直します。

**1 つの語が 2 行に割れることはありません。**語の途中では折り返さず、
入りきらないときは文字を小さくして 1 行に収めます
（`heterogeneous` は iPhone 15 Pro の横画面で 89px、320px 幅の端末でも 1 行）。
日本語の訳は文字の間で折り返しますが、`、。」` が行頭に来ないようにしています。
先に例文を読んで意味を推し量り、そのあとで語と訳を確かめる形です
（設定で「単語 → 訳 → 例文」「訳 → 単語 → 例文」にも変えられます）。

読み上げも同じ並びで、**例文 → 例文の日本語訳 → 単語 → 日本語訳**の順に自動で流れます。

例文の中の**おまけの語**（リストに無い語）には下線が付き、訳まで進むと
画面の下にその語と意味が並びます。

| 操作 | 動き |
| --- | --- |
| **タップ** | 次を表示（最後まで見ていたら、もう一度読み上げ） |
| **長押し** | 一時停止 / 再開（読み上げも自動送りも止まります） |
| **上へスワイプ** | 覚えた。その語は以後の出題から外れます |
| **下へスワイプ** | まだ。同じセットの中で必ずもう一度出ます |
| **左へスワイプ** | 判定せずに次の単語へ |
| **右へスワイプ** | 前の単語へ戻る（直近 50 枚） |
| 何もしない | 読み上げが終わって既定 1 秒で次の表示へ（自動めくり） |
| 最後まで見たら | 既定 1.5 秒で次の単語へ（自動送り）。判定していない語は記録されず、また出ます |

下のアイコンは ★（お気に入り）・⏸（一時停止）・🔊（読み上げの入切）の 3 つだけです。

キーボードでも操作できます：`Space`/`Enter` めくる、`↑`/`2` 覚えた、`↓`/`1` まだ、
`←` 前へ、`→` 次へ、`P` 一時停止、`Esc` やめる。

初回の学習では操作の説明が出ます（設定からもう一度出せます）。

### 二つのモードと、出す順番

学習を始める画面（リストを開いた画面）で、始める前にその場で選べます。選んだ内容は次回も残ります。

| 学習のしかた | 見せるもの | 読み上げ | 間隔の既定 |
| --- | --- | --- | --- |
| **Sentence**（例文つき） | 例文 → 単語 → 訳（おまけの語つき） | 例文 → 例文の訳 → 単語 → 訳 | めくり 1.0 秒 / 送り 1.5 秒 |
| **Word**（単語だけ） | 単語 → 訳 のみ。例文まわりは一切出しません | 単語 → 訳 | めくり 0.5 秒 / 送り 0.8 秒 |

単語だけモードは、覚えた語をテンポよく流して確かめるためのものです。
読み上げも訳を省きたいときは、設定の **Read** を **Word only** にします。
間隔は設定の **Timing · word only** で 0.3〜5 秒に変えられます。

### 2 周する

学習を始める画面の ⟳ の行で **1×** / **2×** を選びます（設定の **Repeat** と同じものです）。

**2×** にすると、1 枚のカードで**同じ組をもう一度はじめから**見せて読み上げます。
最後まで見たところで終わりにせず、また例文（単語だけモードなら単語）から始まります。

| | 1 枚のカードで進むところ |
| --- | --- |
| **1×** | 例文 → 単語 → 訳 |
| **2×** | 例文 → 単語 → 訳 → **例文 → 単語 → 訳** |

読み上げも表示もそのまま 2 度目が流れます。単語だけモードなら 単語 → 訳 を 2 周します。
下の点は「段階 × 周」の数だけ並び、2 周目の頭で少し間が空くので、いま何周目かが分かります。
周と周の間は「めくるまで」の間隔で、2 周し終えてから「送るまで」を数えて次の単語へ進みます。

**出す順番**（⇅ の行）は次の 3 つです。

| アイコン | 順番 | 動き |
| --- | --- | --- |
| ☰ | In order | リストに並んでいる順に出します |
| ⤨ | **Shuffle** | 毎回ちがう順に混ぜます。セットごとに混ぜ直します |
| ✕ | Weak first | ✕ が多い語から先に出します |

**出題する範囲**（⧩ の行）は ✦ 未学習 / ✕ 苦手 / ★ お気に入り / ▤ すべて です。

### 横画面（iPhone を横に持ったとき）

横画面では、上下のバーがカードに重なる形になり、**カードが画面の高さを全部使います**。

- 操作アイコン（★ / ⏸ / 🔊）は**右端に縦に並び**、親指の届く場所に来ます
- 閉じる ✕ と残り枚数は上の端、段階の点と残り時間のバーは下の端
- カードの幅の上限を外し、横に広い画面をそのまま文字に使います
- `env(safe-area-inset-*)` でノッチ側とホームインジケーター側の余白を確保します
- スワイプ面は `touch-action: none`、ブラウザの「戻る」ジェスチャーは
  `overscroll-behavior` で抑えています

iPhone 15 Pro の横画面（852 × 393）では、例文が 79px、単語が 96px ほどになります
（従来の決め打ちでは 19〜31px でした）。

## 学習の進み方

- 選んだ範囲から**1 セットの語数**（既定 20）だけ取り出してキューにします。
- **覚えた**を付けた語はその場でキューから外れ、学習済みになります。以後のセットにも出てきません。
- **まだ**なら 3 枚あとに積み直され、同じセットの中で必ずもう一度出ます。
- 判定せず通り過ぎた語は**記録されず**後ろに回ります（正答率も解答回数も汚れません）。
- セットが片付くと、残りの語で**次のセットが自動的に始まります**。全部覚えると結果の画面になります。

出題する範囲は **未学習 / 苦手 / ★ / すべて**、順番は **リストの順 / ランダム / 苦手を先に** から選べます。

## 設定

| 項目 | 既定 | 説明 |
| --- | --- | --- |
| 見た目 | 端末に合わせる | ライト / ダーク |
| 出題の順番 | リストの順 | ランダム / 苦手を先に |
| 学習のしかた | 例文つき | 「単語だけ（テンポよく）」も選べます（学習を始める画面からも） |
| 出す順番 | リストの順 | ランダム / 苦手を先に（学習を始める画面からも） |
| 段階の並び | 例文 → 単語 → 訳 | 「単語 → 訳 → 例文」「訳 → 単語 → 例文」も選べます |
| 繰り返し | 1× | 2×（1 枚のカードで同じ組をもう一周。学習を始める画面からも） |
| 例文の訳も表示 | オフ | オフのときは読み上げるだけで画面には出しません（単語が出るまでは伏せます） |
| 例文のおまけの語 | オン | 5 列目の語に下線を引き、訳の段階で意味を添えます |
| 読み上げ | オン | 言語ごとに声を選べます（端末に入っている声の一覧から） |
| 読み上げる範囲 | すべて | 例文の訳をとばす / 現地語だけ / 単語だけ |
| 速さ | 1.0 | 0.5〜1.6 |
| 自動めくり | オン | 読み上げが**終わってから**数えて、次の表示へ |
| めくるまで | 1.0 秒 | 0.5〜10 秒 |
| 自動送り | オン | 最後まで見たら次の単語へ |
| 送るまで | 1.5 秒 | 0.5〜10 秒 |
| 単語だけモードのめくるまで | 0.5 秒 | 0.3〜5 秒 |
| 単語だけモードの送るまで | 0.8 秒 | 0.3〜5 秒 |

設定・進み具合・★・取り込んだリストは端末の中（IndexedDB、使えない場合は localStorage）に保存されます。
設定の **バックアップを書き出す / 読み込む** で JSON にまとめて移せます。

## 構成

```
index.html          画面のマークアップ（7 画面）
css/style.css       デザイン（ダーク基調・ライト対応・iPhone の安全領域に対応）
.claude/skills/     このリポジトリで効くスキル（minimal-ui：画面の表記と文字の減らし方）
js/tsv.js           TSV の読み取り（5 列目のおまけの語を含む）と言語の推定
js/session.js       学習セッション（キュー・判定・セットの繰り上がり）
js/links.js         例文の中のおまけの語を見つける（活用形も追う）
js/plan.js          何の順で見せ、何を読み上げるかを決める（モード・並び・読み上げ範囲）
js/store.js         保存（IndexedDB、だめなら localStorage）
js/library.js       リストの棚（収録リストの読み込み・取り込み・進み具合）
js/speech.js        読み上げ（Web Speech API・iPhone の癖に対応）
js/gesture.js       タップ・長押し・スワイプの読み取り
js/app.js           画面の描画とイベント
js/data/*.js        収録リストのデータ
sw.js               オフライン用の Service Worker
manifest.webmanifest / icons/
tools/extract_vocab.py   字幕 → 語彙候補（スキルと同じもの）
tools/check-examples.js  例文の点検（おまけの語がどれだけ入っているか）
tools/make-icons.py      アイコンを作り直す
vocab/              取り込む TSV を置く場所
tests/              テスト
```

`js/tsv.js`・`js/session.js`・`js/links.js`・`js/plan.js` は DOM に依存しないので、Node からそのまま読めます。

## テスト

```sh
npm test    # node --test（Node.js 18 以降・追加の依存なし）
```

TSV の読み取り、学習セッションの動き、おまけの語の見つけ方、
見せる順と読み上げの組み立て、
収録リストのデータの形（列数・重複・例文に単語が入っているか）を見ます。

語彙リストの例文そのものは、別の道具で点検します。

```sh
node tools/check-examples.js vocab/en_papel_s1.tsv --list
```

## 単語リストを足す

収録リストを増やすときは `js/data/` にファイルを作り、`js/library.js` の `BUILTIN` と
`sw.js` の `SHELL`（必要なら）に足します。1 語は
`[term, reading, meaning, example, exampleJa]` の配列です。

ふだんの追加は、アプリの取り込み画面から TSV を入れるほうが簡単です。
