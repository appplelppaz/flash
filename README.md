# Flashcards

言語ごとの単語リストから任意の語数を選び、**選んだ単語がすべて学習済みになるまで繰り返し出題する**単語学習アプリです。
英検1級以上・HSK 6〜9 級・生活フランス語 3000・生活スペイン語 3000 の 4 つの大きな単語リストを収録しています。
1 枚のカードは **単語 → 日本語訳 → その単語を含む例文** の順に、1 つずつ切り替えて表示し、
**単語 → 日本語訳 → 例文 → 例文の日本語訳 → 例文** の順に自動で読み上げます
（例文の日本語訳は読み上げのみで、画面には表示しません）。
学習画面は**画面いっぱい**のレイアウトで、出るのは**語と、意味の分かるアイコンだけ**です。
〇 / ✕ のタップと**上下左右のスワイプ**で操作でき（**iPhone 15 Pro の横画面**を基準に最適化しています）、
何も操作しなければ**自動で次の単語へ**進みます。

ビルド不要・依存パッケージゼロのバニラ JavaScript で、`index.html` を開くだけで動きます。

## 使い方

```sh
open index.html     # そのまま開く
npm start           # ローカルサーバー → http://localhost:8080
```

1. **言語を選ぶ** — 英語 / 中国語 / スペイン語 / フランス語。
2. **単語リストを選ぶ** — 言語ごとに複数のリストがあり、既定のリストが最初から選ばれています。
   選んだリストは言語ごとに記憶されます。
3. **範囲と語数を決める** — すべて / 苦手のみ / ★ のみ、出題語数（既定 20）。
4. **学習する** — カードをタップすると 単語 → 日本語訳 → 例文 と表示が切り替わります。
   画面上の **〇（わかった）/ ✕（わからない）** をタップするか、スワイプで判定します。
   選んだ単語が**すべて学習済みになるまで**終わりません。
5. **結果を見る** — 解答回数・正答率・所要時間・連続学習日数が残ります。

### 学習画面の操作

画面に出るのは**常に 1 つだけ**です。単語 → 日本語訳 → 例文 と切り替えて表示することで、
そのとき見るべきものに集中でき、1 つあたりの文字も大きく取れます。
いま何段階目かはカード下部の点で分かります。

余計な文字は置いていません。画面のタイトル、「単語 / 日本語訳 / 例文」のラベル、
ボタンの文字、操作のたびに出る知らせ — いずれも無く、**アイコンだけ**です。
判定したことは、文字ではなく**カードの色のまたたき**（緑 / 赤）で返します。

〇 は上・✕ は下・‹ › は左右に置いてあり、アイコンの位置がそのままスワイプの向きになっているので、
見た目と操作が一致します。読み上げ・自動送り・お気に入りは、上のバーのアイコンから操作します。

| 操作 | 動作 |
| --- | --- |
| カードをタップ | 次の段階に切り替え（単語 → 日本語訳 → 例文） |
| 〇 をタップ / **上スワイプ** | わかった |
| ✕ をタップ / **下スワイプ** | わからない |
| ‹ をタップ / **左スワイプ** | 前の単語に戻る（直近 50 枚までさかのぼれます） |
| › をタップ / **右スワイプ** | 判定せずに次の単語へ進む |
| 操作しないまま一定時間 | 段階が自動で進み、最後まで見たら次の単語へ移る |

「前の単語に戻る」では判定そのものは取り消しません。もう一度 〇 / ✕ を押せば、
その単語の判定を上書きできます。

#### 横画面（iPhone 15 Pro）への最適化

- 学習中は上のバーごと隠し、ビューポート全体（`100dvh`）を使い、ページのスクロールを止めます。
- `env(safe-area-inset-*)` でノッチ側とホームインジケーター側の余白を確保します。
- 高さが 500px 未満の横向きでは、文字の大きさもアイコンも**高さ基準**（`vh`）で詰めます。
- スワイプ面は `touch-action: none`、ブラウザの「戻る」ジェスチャーは `overscroll-behavior-x: none` で抑えています。

### 自動再生と自動送り

- **自動再生** — 各段階が表示された時点で読み上げます。読み上げの順番は
  **単語（現地語）→ 日本語訳（日本語）→ 例文（現地語）→ 例文の日本語訳（日本語）→ 例文（現地語）** です。
  最後にもう一度例文を聞くことで、意味を理解したうえで音を確認できます。
- **自動送り** — 読み上げが終わってから設定した間隔（既定 4 秒）を計測し、次の段階へ自動的に切り替わります。
  カード下のバーが残り時間を示します。学習画面の「⏸ 自動送り」ボタン（または `P` キー）で
  いつでも一時停止・再開できます。
- 最後の段階まで自動で進んでも判定がなければ、**そのまま次の単語へ移ります**。
  その単語は**記録されずにもう一度出題**されます（正答率や解答回数には影響しません）。
  タップもスワイプもせずに聞き流す使い方でも、進捗が汚れないまま先に進みます。

### キーボード操作

| キー | 動作 |
| --- | --- |
| `Space` / `Enter` | 次の段階を表示 |
| `↑` / `2` | わかった（上スワイプと同じ） |
| `↓` / `1` | わからない（下スワイプと同じ） |
| `←` | 前の単語に戻る |
| `→` | 判定せずに次の単語へ |
| `P` | 自動送りの一時停止・再開 |

## 機能

| 機能 | 内容 |
| --- | --- |
| 言語ごとの単語リスト | 言語ごとに複数のリストを持ち、既定のリストを最初から使えます（下表） |
| 単語リストの切り替え | 学習の設定画面で選択。選んだリストは言語ごとに保存されます |
| 3 段階の切り替え表示 | 単語 → 日本語訳 → 例文 を 1 つずつ表示（例文の日本語訳は読み上げのみ） |
| タップとジェスチャー | 〇 / ✕ のタップ、上下スワイプで判定、左右スワイプで単語の前後移動 |
| 画面いっぱいのレイアウト | 学習中はビューポート全体を使用。iPhone 15 Pro の横画面に最適化 |
| アイコンだけの学習画面 | ラベル・タイトル・知らせの文字を置かず、判定は色のまたたきで返す |
| 出題語数の指定 | 設定のデフォルト（**20**）＋ 学習前に ± ボタン・プリセットで変更 |
| 学習済みまで反復 | 設定回数だけ連続正解するまで、その単語はキューから外れない |
| 自動再生 | 単語 → 日本語訳 → 例文 → 例文の訳 → 例文 の順に Web Speech API で読み上げ |
| 自動送り | 読み上げ後に一定間隔で段階を自動送り。最後まで見たら次の単語へ。一時停止・再開に対応 |
| 出題範囲の切り替え | すべて / 苦手のみ / ★ お気に入りのみ |
| 単語一覧・検索 | 検索（単語・訳・例文）＋フィルター（未学習・学習済み・苦手・★） |
| 自作単語 | 例文つきで追加・編集・削除。収録単語と同じように出題される |
| 学習統計 | 学習済み語数・連続学習日数・通算正答率 |
| バックアップ | 設定・進捗・お気に入り・自作単語を JSON で書き出し／読み込み |
| テーマ | 端末に合わせる / ライト / ダーク |

## 収録している単語リスト

| 言語 | 既定の単語リスト | 語数 | 内容 |
| --- | --- | --- | --- |
| 英語 | **英検1級以上** | 2,077 | 英検1級以上で問われる語彙。発音記号つき |
| 中国語 | **HSK 6〜9級** | 2,051 | HSK 6 級〜9 級（高等）相当の語彙。ピンインつき |
| スペイン語 | **生活スペイン語 3000** | 3,000 | スペイン語圏での生活に必要な 3000 語 |
| フランス語 | **生活フランス語 3000** | 3,000 | フランスでの生活に必要な 3000 語 |

このほか、各言語に「基本単語」リスト（英語 60 語 / 他 40 語）が入っています。
すべての単語に例文と例文の日本語訳がついており、名詞には性（`m.` / `f.`）、
中国語にはピンイン、英語には発音記号が入っています。

## 設定

| 項目 | デフォルト | 説明 |
| --- | --- | --- |
| 出題する単語数 | **20** | 1 回の学習で出題する語数。対象より多い場合は自動で丸められます |
| 学習済みと判定する連続正解回数 | 2 | この回数連続で正解すると学習済み |
| 出題の向き | 単語 → 意味 | 「意味 → 単語」を選ぶと最初の 2 段階が入れ替わります |
| 単語の選び方 | 未学習・苦手を優先 | ランダム / 間違えた回数が多い順 |
| テーマ | 端末に合わせる | ライト / ダーク |
| 読み上げの自動再生 | オン | 単語・日本語訳・例文・例文の訳の自動読み上げ |
| 自動送り | オン | 段階の自動送りと、次の単語への自動移動 |
| 自動送りの間隔 | 4 秒 | 1〜20 秒（読み上げが終わってから計測） |

設定・進捗・お気に入り・自作単語はすべて `localStorage` に保存され、次回起動時に復元されます。

## 学習アルゴリズム

- 選ばれた単語はキューに入り、1 枚ずつ出題されます。
- **正解**すると連続正解数が 1 増え、設定回数に達した時点で学習済みになりキューから外れます。足りない場合は 6 枚ほど後ろへ。
- **不正解**なら連続正解数は 0 に戻り、3 枚ほど後ろに積み直されて必ず再出題されます。
- **判定しなかった**場合（自動送り・右スワイプで通過）は記録せずに後ろへまわします。
- キューが空になる ＝ 選んだ単語がすべて学習済み、でセッション終了です。

## 単語を追加する

アプリ内の「単語一覧・編集 → ＋ 単語を追加」から、例文つきで追加できます。

収録単語そのものを増やす場合は、対象の単語リストのファイルに追記します。

- 基本単語リスト（`js/decks.js` の `BASE_LISTS`）はオブジェクト形式です。

  ```js
  {
    term: 'grateful',
    reading: 'ˈɡreɪtfl',
    meaning: '感謝している',
    example: "I'm grateful for your advice.",
    exampleJa: 'あなたの助言に感謝しています。'
  }
  ```

- 大きな単語リスト（`js/data/*.js`）は `[term, reading, meaning, example, exampleJa]` の配列です。
  追記には開発用スクリプトを使うと、重複の除去と書式そろえを自動で行えます。

  ```sh
  node tools/add-words.js js/data/fr-vie3000.js chunk.js
  ```

`reading` は任意です。`example` を省くと例文の段階が飛ばされ、`exampleJa` を省くと例文の訳の読み上げが省かれます。
単語 ID は「リスト ID:term」で作られるため、途中に挿入しても既存の学習進捗はずれません。

新しい単語リストを足すときは `js/data/` にファイルを作り、`js/decks.js` の `EXTRA_LIST_IDS` と
`index.html` の `<script>` に追加します。既定のリストを変えるときは、その言語の `defaultListId` を書き換えます。
新しい言語は `{ id, code, lang, name, defaultListId }` の deck を足すだけです（`lang` は読み上げ用のロケール）。

## 構成

```
index.html          画面のマークアップ（7 画面）
css/styles.css      デザイン（モノクロ基調・ライト / ダーク対応）
js/decks.js         言語（デッキ）と単語リストの組み立て＋自作単語の合流
js/data/*.js        大きな単語リストのデータ（英検1級以上・HSK6-9・仏西 3000）
js/storage.js       設定・進捗・お気に入り・自作単語・選択中リストの保存
js/session.js       学習セッションと提示順・読み上げ順のロジック（DOM 非依存）
js/app.js           画面の描画とイベント処理
tools/add-words.js  単語リストに単語を追記する開発用スクリプト
tests/              ロジックと単語データのテスト
```
