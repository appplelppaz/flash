# Flashcards 単語帳

Netflix / Language Reactor の字幕から作った語彙リストで学ぶ、**iPhone 向けのフラッシュカード**です。
`netflix-subs-to-vocab` スキルが書き出す TSV をそのまま取り込めます。

- **指だけで学習** — 上下スワイプで判定、左右で前後、タップでめくる、長押しで一時停止。
- **文字の少ない画面** — 学習中はアイコンだけ。判定はカードの色のまたたきで返します。
- **例文から覚える** — 既定は **例文 → 単語 → 訳**。文の中で出会ってから語を確かめる並びです。
- **読み上げ** — 例文（現地語）→ 例文の訳（日本語）→ 単語 → 訳の順に自動で読み上げます。声・速さ・範囲を選べます。
- **自動めくり・自動送り** — 読み上げが終わってから、次の表示へ・次の単語へ自動で進みます。
- **オフラインで動く PWA** — ホーム画面に追加すれば、電波が無くても学習できます。
- **収録リスト 10,128 語** — 英検1級以上 / HSK 6〜9級 / 生活スペイン語 3000 / 生活フランス語 3000。

ビルド不要・依存パッケージゼロのバニラ JavaScript です。

## 使い方

```sh
npm start      # http://localhost:8080 を開く
```

Service Worker（オフライン対応）は `https://` か `localhost` でだけ動きます。
GitHub Pages に置く場合は、リポジトリの Settings → Pages でこのブランチを公開すればそのまま動きます。

iPhone では Safari で開いて **共有 → ホーム画面に追加**。以後はアプリとして起動し、
機内モードでも学習できます。

## 字幕から単語リストを作って取り込む

1. Language Reactor で字幕を書き出す（`lln_excel_subs*.xlsx`）か、`.srt` を用意する。
2. Claude に「この字幕から語彙リストを作って」と頼む（`netflix-subs-to-vocab` スキルが動きます）。
   スキルは同梱の抽出器を使います。

   ```sh
   pip install jieba openpyxl --break-system-packages -q   # jieba は中国語のときだけ
   python3 tools/extract_vocab.py "字幕ファイル" -o candidates.tsv
   ```

3. 出来た `vocab/<lang>_<title>.tsv` を、アプリの **＋ → ファイルを選ぶ／貼り付け → 取り込む**。

取り込める形は **タブ区切り・4 列・ヘッダーなし**です。

```
単語	日本語訳	例文	例文の日本語訳
get away with	（罰を受けずに）やり過ごす	He got away with it again.	彼はまた何のとがめもなく済ませた。
```

ファイル名が `es_lacasadepapel.tsv` のようになっていれば、言語とリスト名を自動で読み取ります。
それ以外は中身から言語を推定します（英語・中国語・スペイン語・フランス語）。
抽出器が出す 8 列の候補ファイル、2〜3 列だけの行、重複行も読めます
（重複はまとめ、訳の無い行は飛ばして理由を知らせます）。

`vocab/en_sample.tsv` は動きを確かめるための見本です。

## 学習画面の操作

画面に出るのは**いま見るものだけ**です。既定では **例文 → 単語 → 訳** の順に進み、
済んだものは小さく残り、いま見るものが大きくなります。
先に例文を読んで意味を推し量り、そのあとで語と訳を確かめる形です
（設定で「単語 → 訳 → 例文」「訳 → 単語 → 例文」にも変えられます）。

読み上げも同じ並びで、**例文 → 例文の日本語訳 → 単語 → 日本語訳**の順に自動で流れます。

| 操作 | 動き |
| --- | --- |
| **タップ** | 次を表示（最後まで見ていたら、もう一度読み上げ） |
| **長押し** | 一時停止 / 再開（読み上げも自動送りも止まります） |
| **上へスワイプ** | 覚えた。その語は以後の出題から外れます |
| **下へスワイプ** | まだ。同じセットの中で必ずもう一度出ます |
| **左へスワイプ** | 判定せずに次の単語へ |
| **右へスワイプ** | 前の単語へ戻る（直近 50 枚） |
| 何もしない | 読み上げが終わって既定 1 秒で次の表示へ（自動めくり） |
| 最後まで見たら | 既定 1.5 秒で次の単語へ（自動送り）。判定していない語は記録されず、また出ます |

下のアイコンは ★（お気に入り）・⏸（一時停止）・🔊（読み上げの入切）の 3 つだけです。

キーボードでも操作できます：`Space`/`Enter` めくる、`↑`/`2` 覚えた、`↓`/`1` まだ、
`←` 前へ、`→` 次へ、`P` 一時停止、`Esc` やめる。

初回の学習では操作の説明が出ます（設定からもう一度出せます）。

## 学習の進み方

- 選んだ範囲から**1 セットの語数**（既定 20）だけ取り出してキューにします。
- **覚えた**を付けた語はその場でキューから外れ、学習済みになります。以後のセットにも出てきません。
- **まだ**なら 3 枚あとに積み直され、同じセットの中で必ずもう一度出ます。
- 判定せず通り過ぎた語は**記録されず**後ろに回ります（正答率も解答回数も汚れません）。
- セットが片付くと、残りの語で**次のセットが自動的に始まります**。全部覚えると結果の画面になります。

出題する範囲は **未学習 / 苦手 / ★ / すべて**、順番は **リストの順 / ランダム / 苦手を先に** から選べます。

## 設定

| 項目 | 既定 | 説明 |
| --- | --- | --- |
| 見た目 | 端末に合わせる | ライト / ダーク |
| 出題の順番 | リストの順 | ランダム / 苦手を先に |
| 出す順番 | 例文 → 単語 → 訳 | 「単語 → 訳 → 例文」「訳 → 単語 → 例文」も選べます |
| 例文の訳も表示 | オフ | オフのときは読み上げるだけで画面には出しません（単語が出るまでは伏せます） |
| 読み上げ | オン | 言語ごとに声を選べます（端末に入っている声の一覧から） |
| 読み上げる範囲 | すべて | 例文の訳をとばす / 現地語だけ / 単語だけ |
| 速さ | 1.0 | 0.5〜1.6 |
| 自動めくり | オン | 読み上げが**終わってから**数えて、次の表示へ |
| めくるまで | 1.0 秒 | 0.5〜10 秒 |
| 自動送り | オン | 最後まで見たら次の単語へ |
| 送るまで | 1.5 秒 | 0.5〜10 秒 |

設定・進み具合・★・取り込んだリストは端末の中（IndexedDB、使えない場合は localStorage）に保存されます。
設定の **バックアップを書き出す / 読み込む** で JSON にまとめて移せます。

## 収録している単語リスト

| 言語 | リスト | 語数 | 内容 |
| --- | --- | --- | --- |
| 英語 | 英検1級以上 | 2,077 | 英検1級以上で問われる語彙。発音記号つき |
| 中国語 | HSK 6〜9級 | 2,051 | HSK 6級〜9級（高等）相当。ピンインつき |
| スペイン語 | 生活スペイン語 3000 | 3,000 | スペイン語圏での生活に必要な語 |
| フランス語 | 生活フランス語 3000 | 3,000 | フランスでの生活に必要な語 |

すべての語に例文と例文の日本語訳が付いています。
収録リストは開いたときに読み込まれるので、起動は速いままです。
収録リストは削除できません（進み具合のリセットはできます）。

## 構成

```
index.html          画面のマークアップ（7 画面）
css/style.css       デザイン（ダーク基調・ライト対応・iPhone の安全領域に対応）
js/tsv.js           TSV の読み取りと言語の推定
js/session.js       学習セッション（キュー・判定・セットの繰り上がり）
js/store.js         保存（IndexedDB、だめなら localStorage）
js/library.js       リストの棚（収録リストの読み込み・取り込み・進み具合）
js/speech.js        読み上げ（Web Speech API・iPhone の癖に対応）
js/gesture.js       タップ・長押し・スワイプの読み取り
js/app.js           画面の描画とイベント
js/data/*.js        収録リストのデータ
sw.js               オフライン用の Service Worker
manifest.webmanifest / icons/
tools/extract_vocab.py  字幕 → 語彙候補（スキルと同じもの）
tools/make-icons.py     アイコンを作り直す
vocab/              取り込む TSV を置く場所
tests/              テスト
```

`js/tsv.js` と `js/session.js` は DOM に依存しないので、Node からそのまま読めます。

## テスト

```sh
npm test    # node --test（Node.js 18 以降・追加の依存なし）
```

TSV の読み取り、学習セッションの動き、収録リストのデータの形（列数・重複・例文に単語が入っているか）を見ます。

## 単語リストを足す

収録リストを増やすときは `js/data/` にファイルを作り、`js/library.js` の `BUILTIN` と
`sw.js` の `SHELL`（必要なら）に足します。1 語は
`[term, reading, meaning, example, exampleJa]` の配列です。

ふだんの追加は、アプリの取り込み画面から TSV を入れるほうが簡単です。
