# 🗂️ フラッシュカード

言語ごとの単語帳から任意の語数を選び、**選んだ単語がすべて学習済みになるまで繰り返し出題する**フラッシュカードアプリです。
ビルド不要・依存パッケージなしのバニラ JavaScript で動きます。

## 使い方

`index.html` をブラウザで開くだけで動きます。

```sh
# ローカルサーバーで開く場合
npm start          # → http://localhost:8080
```

学習の流れ:

1. **言語を選ぶ** — 各言語の学習済み単語数と進捗が一覧に表示されます。
2. **出題する単語数を決める** — 設定のデフォルト値（初期値 20 語）が入った状態で開くので、その場で増減もできます。
3. **学習する** — カードをめくって「わかった / わからなかった」を選びます。
   選んだ単語が**すべて学習済みになるまで**セッションは終わりません。
4. **結果を確認** — 解答回数・正答率・所要時間が表示され、進捗はブラウザに保存されます。

### キーボード操作

| キー | 動作 |
| --- | --- |
| `Space` / `Enter` | 答えを表示 |
| `→` / `2` | わかった |
| `←` / `1` | わからなかった |

## 設定（⚙️ から開く）

| 項目 | デフォルト | 説明 |
| --- | --- | --- |
| 出題する単語数 | **20** | 1 回の学習で出題する単語数。単語帳の総数より多い場合は総数に丸められます。 |
| 学習済みと判定する連続正解回数 | 2 | この回数連続で正解するとその単語は学習済みになります。 |
| 出題の向き | 単語 → 意味 | 「意味 → 単語」「ランダム」も選べます。 |
| 単語の選び方 | 未学習・苦手を優先 | 「ランダム」「間違えた回数が多い順」も選べます。 |

設定と学習進捗は `localStorage` に保存され、次回起動時も引き継がれます。設定画面から進捗をリセットできます。

## 学習アルゴリズム

- 選ばれた単語はキューに入り、1 枚ずつ出題されます。
- **正解**すると連続正解数が 1 増え、設定した回数に達した時点で学習済みになりキューから外れます。まだ足りない場合は 6 枚ほど後ろに戻されます。
- **不正解**だと連続正解数は 0 に戻り、3 枚ほど後ろに積み直されて必ず再出題されます。
- キューが空になる ＝ 選んだ単語がすべて学習済み、となった時点でセッション終了です。

## 収録単語

| 言語 | 語数 |
| --- | --- |
| 英語 | 60 |
| スペイン語 / フランス語 / ドイツ語 / 韓国語 / 中国語 | 各 40 |

## 単語を追加する

`js/decks.js` の該当する言語の `words` に追記するだけです。

```js
{ term: 'grateful', reading: 'ˈɡreɪtfl', meaning: '感謝している' }
```

`reading`（発音・読み・ピンインなど）は任意です。ID は `term` から自動生成されるため、
途中に単語を挿入しても既存の学習進捗はずれません。新しい言語を足したい場合は
`{ id, name, emoji, words }` の deck をひとつ追加してください。

## 構成

```
index.html        画面のマークアップ
css/styles.css    スタイル（ダークモード対応）
js/decks.js       単語帳データ
js/storage.js     設定・学習進捗の保存（localStorage）
js/session.js     学習セッションのロジック（DOM 非依存）
js/app.js         画面の描画とイベント処理
tests/            js/session.js・storage.js・decks.js のテスト
```
