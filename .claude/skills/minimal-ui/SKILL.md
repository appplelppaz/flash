# アプリの見た目の決まり

この人のアプリは、**言葉ではなく形で分かる**ことを目指す。
画面を開いた人が文章を読まずに何ができるか分かり、同じ画面を毎日使っても
読まされる文字が増えないようにする。

新しくアプリを作るときも、既にある画面に手を入れるときも、以下を守る。

## 三つの決まり

### 1. 画面の表記は英語

ボタン・ラベル・見出し・メニュー・設定項目・エラー・空の状態——
**人が読むために画面に置く文字は英語**にする。短い語を選ぶ
（`Start` / `Import` / `Range` / `Order` / `Reset`）。

**ただし、中身は別**。ユーザーのデータ、学習する語、翻訳、本人が入力した文章は
その言語のまま扱う。日本語の訳が入るアプリなら、訳は日本語で出す。
英語にするのは**アプリの枠組み**であって、**中身ではない**。

この区別を外すと、道具としては英語なのに扱う中身も英語に寄ってしまい、
アプリの役に立たなくなる。

### 2. 文字は、アイコンで通じるなら置かない

アイコンにできるものは片っ端からアイコンにする、ではない。
**その形を見て意味が一つに決まるか**で判断する。

置き換えてよいもの（形が意味とほぼ一対一になっている）:

| 意味 | 形 |
| --- | --- |
| 閉じる / 戻る / 進む | ✕ ・ ‹ ・ › |
| 追加 / 削除 | ＋ ・ ゴミ箱 |
| 設定 | 歯車 |
| 検索 | 虫めがね |
| 再生 / 一時停止 | ▶ ・ ⏸ |
| 音 | スピーカー（消音は斜線つき） |
| お気に入り | ★ |
| 決定 / 却下 | ✓ ・ ✕ |
| 一覧 | 横線 3 本 |
| 並べ替え：順番通り / ランダム | 番号つきリスト ・ 交差する矢印 |
| 書き出し / 読み込み | 下向き矢印 ・ 上向き矢印 |

置き換えないもの:

- **その画面にしか無い概念**（「苦手な語」「例文つきモード」）。形を発明しても伝わらない。
- **設定項目の説明**。何を切り替えるのかは言葉でないと決まらない。
- **数**。件数・秒数・割合は数字のまま出す。数字はいちばん短い表記。

迷ったら、**アイコンだけ置いて、その画面の主なボタンにだけ語を添える**。
全部にラベルを付けるより、1 つだけ語があるほうが目が迷わない。

### 3. 装飾を足さない

- 影・枠線・背景の塗り分けは、**要素を分けるために要る場合だけ**。飾りには使わない。
- 色は意味のあるところにだけ置く。強調色は 1 色、成功と失敗に各 1 色、あとは無彩色。
- 余白で区切る。線で区切るのは、余白では足りないときだけ。
- 角丸・文字の太さ・大きさの段階は、画面全体で同じ規則を使い回す。

## 書くときに気をつけること

**アイコンだけのボタンには、必ず名前を持たせる。**
`aria-label`（と、指で触らない環境では `title`）を付ける。
目で見て分かることと、読み上げや操作の補助に分かることは別で、
アイコンだけの画面は後者が抜けやすい。

```html
<button class="icon" aria-label="Settings"><svg><use href="#i-gear"/></svg></button>
```

**アイコンは 1 か所にまとめて定義し、線の太さと角の丸めを揃える。**
SVG の `<symbol>` を 1 つのスプライトに集め、`stroke-width` や `stroke-linecap` を
共通の指定で当てる。別々に描いたアイコンを並べると、そこだけ浮いて見える。

**触れる大きさは 44px 角を下回らない。**
アイコンは小さく見せてよいが、押せる範囲は指に合わせて広く取る。

**初めて開く人向けの説明は、常設しない。**
操作が言葉の説明を要するなら、初回だけ出して、あとは設定から呼べるようにする。
毎回出る説明文は、2 回目以降ずっと邪魔になる。

**空の状態は、次にすることを 1 つだけ示す。**
「まだ何もありません」と書くより、＋ ボタンを置いて、その下に短い一行を添える。

## 仕上げの確認

画面ができたら、次を見てから終える。

1. 画面に出ている**語を数える**。減らせるものは無いか。
   同じことを二度言っている見出しとボタン、説明しなくても分かる説明文が残りやすい。
2. アイコンだけの要素に**名前が付いているか**（`aria-label`）。
3. 日本語が残っていないか。**ただし中身の日本語は残す**（訳・ユーザーの入力・データ）。
4. 色と線が、意味のあるところにだけ使われているか。

## 例

**前**

```html
<h2 class="section-label">出題する範囲</h2>
<div class="segmented">
  <button>未学習</button><button>苦手</button><button>★</button><button>すべて</button>
</div>
<button class="primary">▶ 12 語で学習を始める</button>
```

**後**

```html
<h2 class="section-label">Range</h2>
<div class="segmented">
  <button aria-label="New">…</button>
  <button aria-label="Weak"><svg><use href="#i-close"/></svg></button>
  <button aria-label="Favorites"><svg><use href="#i-star"/></svg></button>
  <button aria-label="All">…</button>
</div>
<button class="primary" aria-label="Start"><svg><use href="#i-play"/></svg><span>12</span></button>
```

見出しは 1 語、選択肢は形、主ボタンは形と数だけ。読む物が無くなっても、
何ができるかは分かる。
